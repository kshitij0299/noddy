## (a) AI and agentic font creation: what is real and what is hype

| Item | What it does / UX | Reality check | Noddy |
|---|---|---|---|
| **VecGlypher** (Meta, CVPR 2026) [arxiv 2602.21461](https://arxiv.org/html/2602.21461) | A language model writes SVG glyph outlines directly, from a style prompt or reference glyph images | Frontier LLMs tested as text-to-glyph baselines produce a recognisable letter less than half the time: Claude Sonnet 4.5 46.7%, GPT-5 44.0%, Gemini 2.5 Pro 24.0%, GPT-5 Mini 4.2%. Open-weight models score about 0. Typical failures are the wrong character and contours that do not close. Absolute coordinates work best. | **Steal** the lesson: the agent must render and check its own output, and should build glyphs by changing existing structure, not drawing blind |
| DeepVecFont-v2 / DualVector [2303.14585](https://arxiv.org/pdf/2303.14585), [2305.10462](https://arxiv.org/pdf/2305.10462) | Generate the rest of a font from a few reference glyphs | Research code only. Thin strokes break, contours fail to close, outlines self-intersect ("g", "r") | **Avoid** as a dependency. Validate every contour (`add_paths` already requires closed contours) |
| Creative Fabrica, FontDance, Tinkerfont ([FontDance](https://futuretools.io/tools/fontdance-chnpe1), [Tinkerfont](https://aiindigo.com/tutorials/getting-started-with-tinkerfont-generate-custom-typefaces-instantly)) | Prompt or image in, TTF out, with a preview | Kerning needs manual cleanup. Extreme weights distort. Image-to-font output is jagged with uniform spacing ([review](https://aiindigo.com/blog/image-to-font-extractor-deep-dive-technical-review)). Results look derivative ("looks like Optima", [TypeDrawers](https://typedrawers.com/discussion/comment/68906)) | **Avoid** a one-shot "generate font" button with no per-glyph control |
| **Font0** ([hunted.space](https://hunted.space/product/font0)) | Starts from open-licensed variable fonts, tunes their axes, lets you edit curves | The most honest design: real structure first, then edit | **Steal** "start from structure, refine" |
| Glyphs MCP (thierryc) ([forum](https://forum.glyphsapp.com/t/exploring-the-role-of-ai-in-typeface-design-with-glyphs/33343?page=2), [lobehub](https://lobehub.com/mcp/thierryc-glyphs-mcp)) | Lets an external agent read and write paths as JSON, set kerning pairs and metrics, and run arbitrary Python (`execute_code`) | No undo tool found. Dry-run exists only at the skill level. Forum skeptics say copying outlines is "three lines of Python" and ask whether the agent could misreport what it did. Designers want AI for tedious, rule-based passes (hinting, a first spacing pass) and to keep the final say | **Avoid** an arbitrary-code escape hatch (Noddy already forbids it, `docs/agent/README.md`). **Steal** the tool granularity |
| **Glyphs Mini MCP** ([glama](https://glama.ai/mcp/servers/r04ujet13c)) | 17 tools. Compiles the font with fontmake and renders a PNG specimen so the agent sees its own letters | The strongest idea in this space | **Steal**: a render-and-check loop after every write |
| Kern On ([manual](https://kern-on.com/manual)); FontLab 8 autospacing and K2 autokerning ([help](https://help.fontlab.com/fontlab/8/whats-new/whats-new-06-metrics-kerning/)) | Kern On: the designer sets a few model pairs and the tool fills in the rest by comparison. FontLab: algorithmic spacing | Kern On is well regarded. Users call FontLab's autospacing "unusable" ([forum](https://forum.fontlab.com/fontlab-8/bug-'auto-spacing'/)) | **Steal** the model-pair arrangement: the human sets a few, the agent propagates |
| TypeDrawers critique of a fully AI-made font ([thread](https://typedrawers.com/discussion/comment/71552/)) | — | Hudson: the overall concept holds, but per-glyph optical corrections fail. Cozens: the rhythm and spacing are off. Phinney: it may not qualify for the OFL licence | The human-correction loop is the product, not an add-on |
| Figma agent ([help](https://help.figma.com/hc/en-us/articles/37998629035799)) | Edits layers on the canvas | Vector editing is still listed as "coming soon" | The space is open: no major tool has agentic vector editing yet |

## (b) Agentic UX patterns

| Pattern | Source | Verdict |
|---|---|---|
| Plan mode that asks clarifying questions in its own UI and saves plans as editable markdown | Cursor 2.1 ([changelog](https://cursor.com/changelog/2-1)) | **Steal**: show the plan as an editable glyph checklist (control glyphs H O n o first, then derived letters) |
| Plans can't be edited; you re-prompt instead. Plan messages cost credits | Lovable ([docs](https://lovable.dev/faq/ai-agent/plan-mode/edit-plans)) | **Avoid**: a plan the user cannot reorder or strike items from |
| Animated indicator on the canvas at the frame being edited; click it to open the steps. Several prompts can run in parallel | Figma agent ([help](https://help.figma.com/hc/en-us/articles/37998629035799)) | **Steal** the indicator: an "agent working" state on the glyph cell and in the edit canvas. **Avoid** parallel runs: Figma users report they [could not be fully undone](https://forum.figma.com/report-a-problem-6/issue-with-the-ai-agent-in-figma-design-55378) |
| Cmd+Z undoes only manual edits. The chat Undo button appears only briefly. No selective revert | Figma ([forum](https://forum.figma.com/ask-the-community-7/does-figma-ai-agent-support-undo-55401)) | **Avoid**: two undo stacks confuse users. Noddy has the same flaw today: "Undo last agent edit" works only while that edit is the latest entry (`src/agent/agent-window.js:153`), and inspector edits are not recorded in history (`docs/agent/README.md`) |
| One checkpoint per prompt; restore code, conversation, or both; manual edits are not tracked | Claude Code ([docs](https://code.claude.com/docs/en/checkpointing)) | **Steal** the per-turn checkpoint, but put it in the same history as manual edits |
| Every change is a version; undo the latest edit with no confirmation; revert to an earlier version with confirmation; bookmarks | Lovable ([docs](https://docs.lovable.dev/features/projects/history)) | **Steal**: named, bookmarkable states ("before lowercase pass") |
| Keep/Undo per change plus a review pane where clicking a file jumps to its diff | Cursor ([forum](https://forum.cursor.com/t/per-change-keep-undo-buttons-missing-after-agent-edits-only-undo-all-available/158983)) | **Steal**: a "Review N changed glyphs" list with a before/after overlay per glyph. **Avoid** the known failures: buttons that vanish and silent auto-apply |
| Variations previewed on the canvas, pick one, thumbs up/down | Illustrator Generative Recolor ([help](https://helpx.adobe.com/illustrator/desktop/use-generative-ai/recolor-artwork-with-generative-recolor.html)) | **Steal** for "3 options for g". **Avoid** a preview that disagrees with the canvas (reported [bug](https://community.adobe.com/questions-652/generative-recolor-window-flickers-mostly-disappears-when-scrolling-color-issues-805469)) |
| User keeps working while the agent runs; "neither of you blocks the other" | Figma ([Muzli](https://muz.li/blog/figma-just-put-an-agent-inside-your-file-heres-what-it-actually-does/)) | **Steal**, with a guard: a glyph the user opens becomes off-limits to the agent until released. Noddy's revision checks already reject stale writes (`src/agent/native-tools.js:57`) |
| Queued messages; Cmd+Enter sends immediately. Stop ends only the current turn while background work continues | Cursor ([forum](https://forum.cursor.com/t/stop-hook-followups-fail-to-land-after-waiting-for-background-tasks/161164)) | **Avoid**: Stop must stop everything. **Steal**: allow a queued follow-up |
| "Take over" from the agent; it resumes from the current state | ChatGPT agent / Operator, Skyvern ([Skyvern docs](https://skyvern.com/docs/cloud/getting-started/monitor-a-run)) | **Steal**: Pause, then edit with the Pen, then Resume, and the agent re-reads the glyph |
| Point-and-edit: select an element, get a properties panel, add annotations that instruct the agent | Figma Make ([help](https://help.figma.com/hc/en-us/articles/31304485164695)), v0 Design Mode ([docs](https://0jo2xuhypsg.v0.build/docs/design-mode)) | **Steal**: select a glyph, contour or point, then "Ask agent about this". Selection becomes the context |
| v0 Design Mode works only on the latest version | v0 | **Avoid**: manual editing must work on any state |
| Token metering where longer threads cost more per message | v0 ([pricing](https://flowstep.ai/blog/v0-pricing/)) | **Steal** visible running cost and context use. **Avoid** opaque credits |
| Bulk edits across many frames | Figma agent; Canva Magic Switch ([newsroom](https://www.canva.com/newsroom/news/magic-studio/)) | **Steal** batch work only as a queue with per-item status. **Avoid** unreviewed bulk changes, which are "subtly wrong" in Figma's own case ([Muzli](https://muz.li/blog/figma-just-put-an-agent-inside-your-file-heres-what-it-actually-does/)) |

## (c) Pro font-editor conventions

| Convention | Source | Verdict |
|---|---|---|
| Glyph grid with a sidebar filter (Categories / Languages > Latin > Basic). A grey badge shows current/total; a checkmark appears when the set is complete | Glyphs ([filtering](https://handbook.glyphsapp.com/filtering/)) | **Steal**: a completion counter per group (A–Z, a–z, 0–9, punctuation) |
| Colour labels and mark colours for workflow state, not exported | Glyphs, RoboFont ([mark colors](https://www.robofont.com/documentation/tutorials/using-mark-colors/)), FontLab flags | **Steal** a fixed status set: empty, draft, agent-edited, needs review, approved, locked. **Avoid** free-form colours |
| Missing glyph shown as a grey cell with a placeholder template | FontLab ([Font Window](https://help.fontlab.com/fontlab-vi/Font-Window/)) | **Steal**: the agent's work queue is visible as ghost cells |
| Double-click a cell to edit. Edit view is a typed text string where any glyph is editable in place; Esc makes the next glyph editable; sample strings for spacing | Glyphs ([edit view](https://glyphsapp.com/learn/edit-view)) | **Steal**: edit in context (HHOHxoxo around the active glyph) |
| Number-key tools (Pen = 2); panels for Preview text, Find glyph (⌘F), Reference font overlay, Glyph info (⌘I), Glyph note, Related glyphs | Fontra ([tools](https://docs.fontra.xyz/reference/editor-view/tools/), [panels](https://docs.fontra.xyz/reference/editor-view/panels/)) | **Steal** the Reference font overlay and Glyph note (the agent writes why it changed the glyph) |
| Space Center: preview string plus a Space Matrix (width, left/right margins) editable inline | RoboFont ([docs](https://doc.robofont.com/documentation/reference/workspace/space-center)) | **Steal** directly under the live specimen |
| Preview panel with text, glyph waterfall and text waterfall, optionally following the active glyph | FontLab ([release notes](https://help.fontlab.com/fontlab/8/whats-new/whats-new-10-glyphs-fonts/)) | **Steal** the follow-the-active-glyph behaviour |
| Opening the pen tool: double-click a glyph, then a single key | Glyphs, Fontra. Noddy already has the pen (`src/edit_canvas/cursors.js:29`) | **Steal**: double-click from the grid or the specimen opens the canvas with the Pen ready |

**Character set name:** the Unicode block is **Basic Latin**, U+0020–007E, the 95 printable ASCII characters. Noddy already defines it (`src/lib/unicode/unicode_blocks_0_bmp.js:3`). The type-industry tier for "English plus essential punctuation" is Google's **GF Latin Kernel**. The next tier, GF Latin Core, covers European languages and is roughly Adobe Latin 3 ([glyphsets](https://pypi.org/project/glyphsets/0.6.2)). For v1 I recommend Basic Latin plus curly quotes, en/em dashes, ellipsis and bullet. I did not verify the exact contents of Kernel.

## Top 10 patterns for Noddy, ranked

1. **Render-and-check after every write**: the agent rasterises the glyph and specimen and compares them (Glyphs Mini MCP). VecGlypher shows that blind drawing fails more than half the time.
2. **Glyph grid as mission control**: a fixed status per cell, completion counts per group, agent presence on the cell (Glyphs badges + Figma's on-canvas indicator).
3. **One shared history**: a checkpoint per agent turn, per-glyph revert, named bookmarks (Claude Code, Lovable). Never a separate agent undo stack (Figma's mistake, Noddy's current limitation).
4. **Review queue**: a before/after overlay with Keep or Revert per glyph, plus Keep all (Cursor review pane).
5. **Live specimen strip and Space Matrix always visible**, following the active glyph (RoboFont, FontLab).
6. **Editable plan as a glyph checklist**: control glyphs first, then derived letters. The user can reorder or strike items (Cursor plan mode; not Lovable).
7. **Double-click opens the glyph in context with the Pen one key away.** The agent stays off a glyph while the user holds it (Glyphs, Fontra, Figma's no-blocking).
8. **Selection as context**: select a glyph or a point, then "Ask agent" (Figma agent, v0 Design Mode).
9. **Model-pair contract for spacing and kerning**: the user sets a few pairs, the agent propagates, the user locks the results (Kern On).
10. **Honest budget and control**: glyphs in scope, steps, tokens and cost, and a Stop that halts everything (avoid Cursor's partial Stop; current loop caps at `src/agent/agent-controller.js:49-50`).
